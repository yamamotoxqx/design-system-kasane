レイアウト

画面は、面を重ねて組み立てます。余白は部品の外側ではなく、並べる側で決めます。

面の順番

ページの背景の上にカードを置き、カードの中のまとまりは中の面で作ります。同じ色の面を直接重ねないでください。

今週の予定

  • 図書館の本を返す
  • 発表スライドの確認
HTML
<div class="k-card">
  <h3 class="k-card-title">今週の予定</h3>
  <ul class="k-list">
    <li class="k-list-item"><span class="k-list-item-main">図書館の本を返す</span></li>
    <li class="k-list-item"><span class="k-list-item-main">発表スライドの確認</span></li>
  </ul>
</div>
場所面角丸
ページの背景--bgなし
カード、パネル--surface--r-lg
中の面、リストの行--surface-2--r-md
ホバー、押下--surface-3同じ

並べ方

部品どうしの間隔は、親の gap で決めます。部品に外側の余白(margin)を持たせないので、どこに置いても間隔がそろいます。

CSS
.page  { display: flex; flex-direction: column; gap: var(--space-7); }  /* 章と章の間 */
.cards { display: grid; gap: var(--space-4);
         grid-template-columns: repeat(auto-fit, minmax(min(100%, 280px), 1fr)); }

幅

対象幅
文章最大38em(全角で35〜40文字)
本文の列最大1040px
画面の左右の余白16px以上

画面の幅による切り替え

このサイトは、2つの幅で配置を変えています。カードの並びは、幅に応じて自動で折り返します。

幅変わること
1100px以下右の目次を隠す
820px以下左のナビゲーションをメニューに入れ、1列にする
CSS
.shell { display: grid; grid-template-columns: 248px minmax(0, 1fr) 216px; gap: var(--space-5); }
@media (max-width: 1100px) { .shell { grid-template-columns: 248px minmax(0, 1fr); } }
@media (max-width: 820px)  { .shell { grid-template-columns: minmax(0, 1fr); } }
